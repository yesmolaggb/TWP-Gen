# Resource samples

The complete dictionary and frequency resources are about 536 MB, so they are
not stored in this Git repository. This directory provides 10 representative
entries from each resource:

- `verb_sense_dict_w_features.sample.json`
- `verb_freq.sample.json`
- `all_lemma_freq.sample.json`

The full resources can be rebuilt with the programs in `experiments/dictionary/`.
